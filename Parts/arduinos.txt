Arduinos
========

We use two Arduino Uno R3 boards.

Master Arduino:
- handles the motor driver and tank movement
- reads the front ultrasonic and scan arm sensors
- reads the IR sensor
- reads the MPU-6050
- moves the pan/tilt arm
- sends MPU data to the slave

Slave Arduino:
- runs the LCD
- reads the light sensor
- reads the TMP36 temperature sensor
- reads the side ultrasonic
- sends obstacle alerts back to the master

Why we split it:
- one Uno was running out of pins once we added everything
- keeping the faster driving logic on one board also made the code easier to manage

Both boards are standard Uno R3 boards with ATmega328P chips.
